# Fichero oficial del INE

Guarda aquí, **tal cual lo descargas de la web del INE**, el fichero «Relación de municipios y sus códigos por
provincias» (xlsx o csv; si es un `.xls` antiguo, ábrelo y guárdalo como xlsx sin tocar nada) y ejecuta:

```bash
npm run ine:importar -- docs/oficial/ine/<nombre del fichero>
```

Instrucciones completas: README → «Códigos de municipio INE».
