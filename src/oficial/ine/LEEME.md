# Relación de municipios del INE (generada)

Aquí van los `municipios-AAAA-MM-DD.json` que genera `npm run ine:importar` a partir del fichero oficial guardado en
`docs/oficial/ine/`. **No se editan a mano**: una prueba comprueba que cada JSON se regenera idéntico desde su fichero
oficial (misma huella SHA-256). Si conservas también la relación del año anterior, la app avisa de los códigos dados de
baja (p. ej. por fusión). Instrucciones completas: README → «Códigos de municipio INE».
